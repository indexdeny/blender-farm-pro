# Technical case: two packaging examples

The engineering problem was insufficient control over geometry, text and lighting in a browser-based image-generation workflow. The project introduced a headless Blender/Cycles route with an explicit passport-to-render boundary, procedural construction, independently sourced SVG/TTF artwork, physical relief and inspectable scene evidence.

Two examples reached owner-reported workplace acceptance: Viagra 74-min and Cialis 59-min. Their source filenames, hashes and 2048-square dimensions are recorded in preview-provenance.json. The previews are historical accepted results, not a claim that the latest checkout recreates the original bytes. Exact creation revisions are unknown because the working implementation included uncommitted code.

The owner's contribution was requirements, architecture, geometry/material/validation specification, coordination of AI-assisted implementation, visual evaluation and iterative refinement. Further catalogue development was discontinued for budget reasons. This portfolio release does not expand the project into a 391-product visual-completion effort.

Current measured reproduction, test counts, unresolved checks and publication state are reported at the repository root. Rights evidence is separate from image acceptance and technical quality.
