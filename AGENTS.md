# AGENTS.md — Blender Farm Pro

Сгенерировано audit-pack `project-audit-rebuild` · 2026-08-10 · REGISTER VERSION: v1

## 1. Project Overview

Форк PharmaGen PRO, разрабатывающий headless-Blender как движок пакшотов. Превращает
JSON-паспорт SKU (бренд, дозировка, палитра, геометрия упаковки) в изображение
фармацевтической упаковки. 391 SKU в каталоге.

**CORE FLOW:** паспорт SKU → манифест (контракт Stage 1→2) → сцена Blender → PNG →
WEBP 1600², ≤500 КБ → **ценность: пакшот, текст на котором нельзя выдумать.**

**MATURITY:** MVP — core flow работает, каталог целиком не пройден, продакшен-обязательств нет.

## 2. Source of Truth

- **Канон поведения:** код. При конфликте с документацией прав код; расхождение —
  дефект документа, а не повод «привести код в соответствие».
- **Канон границы Stage 1 → Stage 2:** `schemas/render_manifest.schema.json`.
  `src/render_manifest.py` — его единственная реализация. Ни один потребитель не
  собирает форму манифеста руками.
- **Канон маршрутизации:** `agent_1_router()` в `src/passport_generator.py`. Рендереры
  его **вызывают**, а не воспроизводят.
- **Канон данных каталога:** `03_knowledge_graph/`. Директории `SSOT/` больше нет.
- **ПРАВИЛО:** второй источник правды не создаётся ни при каких обстоятельствах.

## 6. Conventions

- Стемы файлов — `-min` (`1-min.json` → `1-min.png`). Голые числовые имена не возвращать.
- Корневые `pass_tomd.py`, `webp_converter.py`, `gemini_image_generator.py` — шимы;
  править модуль в `src/`, не шим.
- `blender.engine_type` — реальный идентификатор движка Blender (`CYCLES`,
  `BLENDER_EEVEE`), недоступный — фатален. **Никогда не интроспектировать enum
  движка**: он динамический и возвращает заглушку.

2. **Требуется второй источник правды** — остановиться. Кеш допустим только с TTL и

исходные ограничения. Неиспользуемый фото-эксперимент `reference_projection`
исключается из публичного candidate и сохраняется в приватном recovery.

пиксельная воспроизводимость, визуальная оценка и права публикации — отдельные
утверждения; их нельзя подменять одним зелёным тестовым прогоном.
